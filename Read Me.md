# Portfolio Solène Avril

Maquette de portfolio réalisée uniquement en HTML et CSS, à partir des annexes du projet fil rouge.

## Fichiers
- `index.html` : structure de la page
- `style.css` : mise en forme et adaptation mobile/tablette

## Tester le site
Ouvrir `index.html` dans un navigateur. Une connexion Internet est nécessaire pour afficher les photographies hébergées sur Unsplash.

## Publier avec GitHub Pages
1. Créer un dépôt GitHub (par exemple `portfolio-solene-avril`).
2. Ajouter `index.html`, `style.css` et `README.md` à la racine du dépôt.
3. Aller dans **Settings > Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`, puis cliquer sur **Save**.
6. Attendre quelques instants : GitHub affichera l'adresse du site dans la section Pages.

Les liens de catégories et réseaux sociaux sont des liens de démonstration. Les images sont chargées depuis Unsplash.


## Photos aléatoires
Les images utilisent le service externe Picsum Photos. Les adresses sont différentes pour chaque emplacement et le service peut fournir de nouvelles photos lors d'un rechargement. Comme il s'agit d'un service externe sans JavaScript, le renouvellement n'est pas garanti à chaque visite par tous les navigateurs (cache).

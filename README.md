# Portfolio photographique – Solène Avril

Réalisation d'un site web mettant en valeur le travail d'une photographe fictive, Solène Avril. L'objectif est de proposer une interface simple et esthétique permettant de découvrir différentes photographies à travers une galerie et un système de navigation par thèmes.

🔗 **Accéder au site :** (https://samuel-rt-tp2-2.github.io/Projet-fils-rouge/)

## Langages et outils

- HTML5 pour construire le contenu du site.
- CSS3 pour gérer l'apparence et la disposition des éléments.
- Flexbox et Grid pour structurer les différentes zones.
- Media queries pour adapter le site aux différents écrans.

## Ce que propose le site

- Une interface qui s'ajuste automatiquement aux ordinateurs, tablettes et smartphones.
- Un espace de navigation permettant de parcourir les différentes catégories de photographies.
- Une galerie dont la présentation évolue selon la résolution de l'écran.
- Des visuels récupérés depuis le service Lorem Picsum.
- Des icônes provenant de Font Awesome.
- Des typographies importées depuis Google Fonts : Yeseva One et Montserrat.
